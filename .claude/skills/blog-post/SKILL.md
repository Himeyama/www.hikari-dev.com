# ブログ記事作成スキル

新しいブログ記事を、日本語執筆 → 多言語翻訳 → OGP 画像生成まで一括で行う。詳細な文体・配置ルールは `/CLAUDE.md` を参照すること（このスキルはその手順を実行順に整理したチェックリスト）。

## 手順

1. **題材の調査**
   - 紹介対象が GitHub リポジトリ等の場合、`gh api repos/{owner}/{repo}` や `gh api repos/{owner}/{repo}/contents/README.md` で概要・技術スタック・使い方を正確に把握する（README を要約ではなく実際に読むこと）。
   - 既存記事 (`blog/` 内の直近のもの数本) を読み、文体・構成・タグの傾向を確認する。

2. **ファイル名を決定**
   - `YYYY-MM-DD-slug.md` 形式。日付は今日の日付、slug は内容を表す英語ケバブケース。

3. **日本語本文を執筆** — `blog/YYYY-MM-DD-slug.md`
   - フロントマターは `title` / `authors: hikari` / `tags` のみ（`description` `image` は後述の手順で自動付与するまで不要）。
   - 文体は `CLAUDE.md` の日本語スタイルガイドに従う（である調が既定。ユーザーがですます調を指定した場合はそれに従う）。
   - 冒頭 1 - 2 文の概要 + `<!-- truncate -->` を入れる。
   - 見出し (`##`)、コードブロックの言語指定を徹底する。

4. **ユーザーに日本語版の確認・添削を仰ぐ**
   - 日本語版を書いたら、翻訳作業に進む前にユーザーが内容を編集・確定する時間を与える。ユーザーが直接ファイルを編集した場合は、その最終版を翻訳のソースにすること（編集前の内容を翻訳しない）。

5. **多言語版を作成**（日本語版確定後）
   - 英語: `i18n/en/docusaurus-plugin-content-blog/YYYY-MM-DD-slug.md`
   - 繁體中文: `i18n/zh-TW/docusaurus-plugin-content-blog/YYYY-MM-DD-slug.md`
   - ファイル名は日本語版と同一、`tags` も同じ値を使用する。
   - コードブロックの中身（コマンド・コード）はそのまま流用し、翻訳しない。
   - 日本語版の構成・段落・見出しを忠実に翻訳する（省略・追加をしない）。

6. **OGP 画像を生成**
   ```bash
   node scripts/generate-ogp.js --file YYYY-MM-DD-slug.md
   ```
   - 日本語版・英語版のフロントマターに `image: /img/ogp/YYYY-MM-DD-slug.webp` が自動追加される (WebP、品質 80)。
   - zh-TW 版はスクリプトの対象外なので、同じ `image:` 行を手動で追加する。
   - 記事内に代表画像がある場合はタグベース OGP の代わりにその画像パスを `image:` に設定してもよい（その場合はスクリプト実行不要）。

7. **ビルド確認**（プッシュ前に必須、CLAUDE.md のルール）
   ```bash
   pnpm run build
   ```

## 注意事項

- `authors` は常に `hikari`。
- 画像を使う記事は `static/img/blog/YYYY-MM-DD-slug/` に配置する。
- 免責事項など法的に重要な文章は、要約せず原文の趣旨を保ったまま翻訳する。
