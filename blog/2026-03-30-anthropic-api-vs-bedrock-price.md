Claude を API 経由で使う場合、**Anthropic API を直接使う**か、**AWS Bedrock 経由で使う**かの 2 択がある。基本料金はほぼ同額だが、バッチ処理や AWS エコシステムとの統合面で差がある。

<!-- truncate -->

> 単位: USD / 1M トークン (MTok) 。2026 年 3 月時点の情報。

## 基本料金 (オンデマンド) 

| モデル | 項目 | Anthropic API | Bedrock |
|--------|------|:---:|:---:|
| **Claude Opus 4.6** | 入力 | $5.00 | $5.00 |
| | 出力 | $25.00 | $25.00 |
| **Claude Sonnet 4.6** | 入力 | $3.00 | $3.00 |
| | 出力 | $15.00 | $15.00 |
| **Claude Haiku 4.5** | 入力 | $1.00 | $1.00 |
| | 出力 | $5.00 | $5.00 |
| **Claude Sonnet 4.5** | 入力 | $3.00 | $3.00 |
| | 出力 | $15.00 | $15.00 |

**基本料金は Anthropic API と Bedrock で完全に同額。**

Bedrock には Long Context バリアント (別 SKU) が存在するが、同価格で提供されている。Anthropic API では Long Context は通常モデルに統合済みで別 SKU はない。

## キャッシュ料金

プロンプトキャッシュ (Prompt Caching) の料金も両者で同額。

| モデル | キャッシュ種別 | Anthropic API | Bedrock |
|--------|-------------|:---:|:---:|
| **Claude Opus 4.6** | 5分キャッシュライト | $6.25 | $6.25 |
| | 1時間キャッシュライト | $10.00 | $10.00 |
| | キャッシュリード | $0.50 | $0.50 |
| **Claude Sonnet 4.6** | 5分キャッシュライト | $3.75 | $3.75 |
| | 1時間キャッシュライト | $6.00 | $6.00 |
| | キャッシュリード | $0.30 | $0.30 |
| **Claude Haiku 4.5** | 5分キャッシュライト | $1.25 | $1.25 |
| | 1時間キャッシュライト | $2.00 | $2.00 |
| | キャッシュリード | $0.10 | $0.10 |

キャッシュライトは TTL に応じて 5 分 (短期) と 1 時間 (長期) の 2 段階がある。長期キャッシュほど書き込みコストが高いが、繰り返し参照するシステムプロンプトが長い場合はリード料金の節約で十分ペイする。

## バッチ処理料金 (Bedrock のみ明示) 

Bedrock では非同期バッチ API がオンデマンド料金の **50% OFF** で利用できる。

| モデル | バッチ入力 | バッチ出力 |
|--------|:---:|:---:|
| **Claude Opus 4.6** | $2.50 | $12.50 |
| **Claude Sonnet 4.6** | $1.50 | $7.50 |
| **Claude Haiku 4.5** | $0.50 | $2.50 |
| **Claude Sonnet 4.5** | $1.50 | $7.50 |

Anthropic API 側にもバッチ処理は存在するが、料金ページへの掲載形式が異なるため本比較では省略している。大量データの一括処理 (ログ解析、埋め込み生成など) でバッチを多用するなら Bedrock 経由の方がコストを半減できる。

## どちらを選ぶか

- **コスト最優先・バッチ多用**: 基本料金は同額なので差はない。バッチ処理を大量に使うなら Bedrock が半額で有利。
- **AWS エコシステムに統合済み**: IAM 認証、CloudWatch ログ、VPC 内閉鎖通信が必要なら Bedrock 一択。
- **シンプルな利用・プロトタイプ**: Anthropic API の方が API キー 1 本で始められ、セットアップが簡単。
