## 建立圖表

首先載入所需的函式庫。

```py
import matplotlib.pyplot as plt
import numpy as np
```

### 單一圖表

```py
fig, ax = plt.subplots()
```

![](/img/blog/2024-04-20-pyplot/001.png)

### 2 x 3 的圖表

```py
fig, axs = plt.subplots(2, 3)
```

![](/img/blog/2024-04-20-pyplot/002.png)

## 繪製圖表

**繪製拋物線**

```py
x = np.linspace(-1, 1, 201)
y = x ** 2

fig, ax = plt.subplots()
ax.plot(x, y)
```

![](/img/blog/2024-04-20-pyplot/003.png)

**用點繪製拋物線**

```py
fig, ax = plt.subplots()

x = np.linspace(-1, 1, 21)
y = x ** 2

ax.plot(x, y, 'o')
```

![](/img/blog/2024-04-20-pyplot/016.png)

**顏色設為橘色**

```py
fig, ax = plt.subplots()

x = np.linspace(-1, 1, 21)
y = x ** 2

ax.plot(x, y, color="tab:orange")
```

![](/img/blog/2024-04-20-pyplot/017.png)

標準顏色如下：

|顏色|字串|
|--|--|
|藍|tab:blue|
|橘|tab:orange|
|綠|tab:green|
|紅|tab:red|
|紫|tab:purple|
|棕|tab:brown|
|粉紅|tab:pink|
|灰|tab:gray|
|橄欖|tab:olive|
|青|tab:cyan|

**設定線的粗細為 4**

```py
fig, ax = plt.subplots()

x = np.linspace(-1, 1, 21)
y = x ** 2

ax.plot(x, y, lw=4)
```

![](/img/blog/2024-04-20-pyplot/018.png)

## 設定標題

**將標題設為 Title**

```py
fig, ax = plt.subplots()
ax.set_title("Title")
```

![](/img/blog/2024-04-20-pyplot/010.png)

## 設定軸標籤
### 設定 x 軸標籤

**將 x 軸標籤設為 Time (s)**

```py
fig, ax = plt.subplots()
ax.set_xlabel("Time (s)")
```

![](/img/blog/2024-04-20-pyplot/011.png)

### 設定 y 軸標籤

**將 y 軸標籤設為 Distance (m)**

```py
fig, ax = plt.subplots()
ax.set_ylabel("Distance (m)")
```

![](/img/blog/2024-04-20-pyplot/012.png)

## 設定圖表的上限與下限

**將上限設為 100**

```py
fig, ax = plt.subplots()
ax.set_ylim(top=100)
```

![](/img/blog/2024-04-20-pyplot/004.png)

**將下限設為 -100**

```py
fig, ax = plt.subplots()
ax.set_ylim(bottom=-100)
```

![](/img/blog/2024-04-20-pyplot/005.png)

**將上限設為 100，下限設為 -100**

```py
fig, ax = plt.subplots()
ax.set_ylim([-100, 100])
```

![](/img/blog/2024-04-20-pyplot/006.png)

## 設定刻度

**設定 x 軸刻度**

```py
fig, ax = plt.subplots()
xticks = range(6)
ax.set_xticks(xticks)
```

![](/img/blog/2024-04-20-pyplot/019.png)

**設定 x 軸刻度和刻度標籤**

```py
fig, ax = plt.subplots()
xticks = range(6)
ax.set_xticks(xticks, [f"{xtick}m" for xtick in xticks])
```

![](/img/blog/2024-04-20-pyplot/020.png)

**設定 y 軸刻度**

```py
fig, ax = plt.subplots()
yticks = [i * 20 for i in range(6)]
ax.set_yticks(yticks)
```

![](/img/blog/2024-04-20-pyplot/021.png)

**設定 y 軸刻度和刻度標籤**

```py
fig, ax = plt.subplots()
yticks = [i * 20 for i in range(6)]
ax.set_yticks(yticks, [f"{ytick}%" for ytick in yticks])
```

![](/img/blog/2024-04-20-pyplot/022.png)

## 調整圖表間距

**將縱向間距設為 0.2，橫向間距設為 0.3**

```py
fig, ax = plt.subplots(3, 3)
fig.subplots_adjust(hspace=0.2, wspace=0.3)
```
![](/img/blog/2024-04-20-pyplot/031.png)

**自動設定間距**

```py
fig, ax = plt.subplots(3, 3)
fig.tight_layout()
```

![](/img/blog/2024-04-20-pyplot/032.png)

## 儲存圖片

**以 PNG 格式儲存**

```py
fig, ax = plt.subplots()
plt.savefig("graph.png")
```

![](/img/blog/2024-04-20-pyplot/graph.png)

**以 SVG 格式儲存**

```py
fig, ax = plt.subplots()
plt.savefig("svg.png")
```

![](/img/blog/2024-04-20-pyplot/graph.svg)

**以 PDF 格式儲存**

```py
fig, ax = plt.subplots()
plt.savefig("svg.pdf")
```

[graph.pdf](/img/blog/2024-04-20-pyplot/graph.pdf)

**以 300 dpi 儲存**

```py
fig, ax = plt.subplots()
plt.savefig("graph300.png", dpi=300)
```

![](/img/blog/2024-04-20-pyplot/graph300.png)
