本指南說明如何在不需要螢幕的情況下設定 Raspberry Pi。

-   需要可連接網路線進行有線連線的 Raspberry Pi 裝置。
-   需要一台電腦來操作 Raspberry Pi。

# 安裝
安裝 Raspberry Pi Imager，選擇 OS。選擇要寫入的 micro SD 卡，然後點擊 WRITE。

![Raspberry Pi Imager](/img/blog/2021-08-16-raspi/imager.png)

# 設定
## 啟用 SSH
啟用 SSH 可讓您遠端操作 Raspberry Pi。

重新插入 micro SD 卡，並在根目錄中直接建立一個名為 `ssh` 的文字檔案，不需要副檔名。

![Raspberry Pi enable SSH](/img/blog/2021-08-16-raspi/ssh.png)

## 啟用 VNC
開啟 `config.txt`，取消以下幾行的註解並儲存：
```
framebuffer_width=1280
framebuffer_height=720
```

![Raspberry Pi enable VNC](/img/blog/2021-08-16-raspi/config.png)

## 開機
將 micro SD 卡插入 Raspberry Pi，連接電源並開機。

## 透過 SSH 連線
使用主機名稱 `raspberrypi`、使用者名稱 `pi`、密碼 `raspberry` 進行連線。

![Raspberry Pi connect SSH](/img/blog/2021-08-16-raspi/ssh-c.png)

## 更新套件
```sh
sudo apt update
sudo apt upgrade -y
```

## 啟用 VNC
```sh
sudo raspi-config
```

![Raspberry Pi config](/img/blog/2021-08-16-raspi/raspi-config.png)

選擇 `3 Interface Options`，然後選 `P3 VNC`，再選 `YES`。按 `Finish` 關閉。

## 透過 VNC 連線
![Raspberry Pi VNC viewer](/img/blog/2021-08-16-raspi/vncviewer.png)

使用與 SSH 相同的使用者名稱和密碼。

![Raspberry Pi VNC connected](/img/blog/2021-08-16-raspi/VNC-c.png)

## 啟用 Wi-Fi
透過 VNC 啟用 Wi-Fi 後，就不再需要有線連線，只需電源即可操作 Raspberry Pi。
