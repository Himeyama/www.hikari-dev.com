建立 DLL 並編譯 C 的備忘錄
## 函式庫
### 原始碼檔案
```c
// gcd.c
int gcd(int a, int b){
    return !b ? a : gcd(b, a % b);
}
```

### 標頭檔
```c
// gcd.h
#ifndef TEST_H
#define TEST_H

int gcd(int a, int b);

#endif
```

### 程式碼
```c
#include <stdio.h>
#include "gcd.h"

int main(void){
    printf("%d
", gcd(24, 36));
}
```

## 編譯

### 建立 DLL
```sh
gcc gcd.c -shared -o gcd.dll
```

### 編譯
```sh
gcc main.c -lgcd -L.
```
