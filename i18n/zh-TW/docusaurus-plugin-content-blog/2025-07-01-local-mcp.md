## 處理流程
使用 MCP 時，我問了 Copilot 小幫手，LLM 用戶端會以什麼樣的流程進行處理。

以下為序列圖。

```mermaid
sequenceDiagram
    autonumber
    participant User as 使用者
    participant Client as LLM 用戶端
    participant LLM as LLM（大規模語言模型）
    participant MCP as MCP（Model Context Protocol）
    participant Tool as 外部工具（API / Shell / DB）

    %% 初始化階段
    Client->>MCP: 要求工具定義清單
    MCP-->>Client: 工具定義（函式名、參數、說明等）

    %% 對話階段
    User->>Client: 傳送輸入
    Client->>LLM: 傳送使用者輸入 + 工具定義
    LLM->>LLM: 解析提示詞並理解意圖
    LLM->>LLM: 判斷是否需要呼叫工具

    alt 需要呼叫工具
        LLM->>Client: 要求呼叫工具（函式名、參數）
        Client->>MCP: 請求呼叫工具
        MCP->>Tool: 執行外部工具
        Tool-->>MCP: 回傳執行結果
        MCP-->>Client: 回傳結果
        Client->>LLM: 傳送執行結果（function result）
        LLM->>LLM: 產生回應
    else 不需呼叫工具
        LLM->>LLM: 直接產生回應
    end

    LLM-->>Client: 回傳回應
    Client-->>User: 顯示回應
```

這裡重要的是：

1. ①② 取得工具定義
2. ④ 傳送工具定義
3. ⑦ 工具呼叫要求
4. ⑧⑨⑩⑪ 工具呼叫
5. ⑫ 傳送執行結果

與 MCP 有關的部分是 1. 和 4.，而與 Function calling（函式呼叫）幾乎相同的部分是 2.、3. 和 5.。

## 在終端機輸入指令來呼叫看看

來嘗試以標準輸入使用本地 MCP。

我用 Windows PowerShell 執行指令。

### 取得工具清單
舉例取得 `@modelcontextprotocol/server-filesystem` 的工具清單。

```ps1
> @{ jsonrpc = "2.0"; method = "tools/list"; id = 1 } | ConvertTo-Json -Compress | npx @modelcontextprotocol/server-filesystem $HOME | ConvertFrom-Json | ConvertTo-Json -Depth 10
Secure MCP Filesystem Server running on stdio
Allowed directories: [ 'C:\\Users\\hikari' ]
{
  "result": {
    "tools": [
      {
        "name": "read_file",
        "description": "Read the complete contents of a file from the file system. Handles various text encodings and provides detailed error messages if the file cannot be read. Use this tool when you need to examine the contents of a single file. Only works within allowed directories.",
        "inputSchema": {
          "type": "object",
          "properties": {
            "path": {
              "type": "string"
            }
          },
          "required": [
            "path"
          ],
          "additionalProperties": false,
          "$schema": "http://json-schema.org/draft-07/schema#"
        }
      },
      ...
    ]
  }
}
```

把 `tools/list` 透過標準輸入傳入，就能以 JSON 格式取得工具清單。

### 呼叫工具
根據工具資訊來呼叫它。

```ps1
> @{ jsonrpc = "2.0"; method = "tools/call"; params = @{name = "read_file"; arguments = @{path = ".gitconfig"}}; id = 2 } | ConvertTo-Json -Compress -Depth 10 | npx @modelcontextprotocol/server-filesystem $HOME | ConvertFrom-Json | ConvertTo-Json -Depth 10
Secure MCP Filesystem Server running on stdio
Allowed directories: [ 'C:\\Users\\hikari' ]
{
  "result": {
    "content": [
      {
        "type": "text",
        "text": "..."
      }
    ]
  },
  "jsonrpc": "2.0",
  "id": 2
}
```
