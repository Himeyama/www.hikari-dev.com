這篇備忘錄記錄了 Git 的一些常用命令和概念。

:::info
Git 是一個免費開源的分布式版本控制系統 (Distributed Version Control System, DVCS)，旨在以速度和效率處理從小到大的所有項目。它允許開發人員跟踪其程式碼庫中的更改，協作開發，並在需要時回溯到早期版本。
:::

## 1. 基本操作

### 初始化倉庫

在當前目錄中創建一個新的 Git 倉庫：

```bash
git init
```

### 克隆倉庫

克隆一個遠端倉庫到本地：

```bash
git clone <repository_url>
```

範例：
```bash
git clone https://github.com/git/git.git
```

### 添加文件到暫存區

將文件添加到暫存區（準備提交）：

```bash
git add <file_name>      # 添加單個文件
git add .                # 添加所有更改過的文件
git add -u               # 添加所有已追蹤但已修改/刪除的文件（不包括新文件）
git add -A               # 添加所有更改過的文件（包括新文件、修改和刪除）
```

### 提交更改

將暫存區中的更改提交到本地倉庫：

```bash
git commit -m "提交信息"
```

### 檢查狀態

查看工作目錄和暫存區的狀態：

```bash
git status
```

### 查看更改

查看工作目錄和暫存區之間的差異：

```bash
git diff                 # 查看未暫存的更改
git diff --staged        # 查看已暫存但未提交的更改
git diff HEAD            # 查看工作目錄與最新提交的差異
```

## 2. 分支操作

### 列出分支

列出本地分支：

```bash
git branch
```

列出所有分支（包括遠端分支）：

```bash
git branch -a
```

### 創建分支

創建一個新分支：

```bash
git branch <new_branch_name>
```

### 切換分支

切換到指定分支：

```bash
git checkout <branch_name>
```

創建並切換到新分支：

```bash
git checkout -b <new_branch_name>
```

### 合併分支

將一個分支的更改合併到當前分支：

```bash
git merge <branch_to_merge>
```

### 刪除分支

刪除本地分支（需要先切換到其他分支）：

```bash
git branch -d <branch_name>      # 刪除已合併的分支
git branch -D <branch_name>      # 強制刪除未合併的分支
```

## 3. 遠端倉庫操作

### 查看遠端倉庫

查看配置的遠端倉庫：

```bash
git remote -v
```

### 添加遠端倉庫

添加一個遠端倉庫：

```bash
git remote add <remote_name> <repository_url>
```

範例：
```bash
git remote add origin https://github.com/yourusername/your_repo.git
```

### 推送更改

將本地分支的更改推送到遠端倉庫：

```bash
git push <remote_name> <branch_name>
```

範例：
```bash
git push origin main
```

### 拉取更改

從遠端倉庫拉取更改到本地分支：

```bash
git pull <remote_name> <branch_name>
```

範例：
```bash
git pull origin main
```

## 4. 歷史記錄

### 查看提交歷史

查看提交歷史：

```bash
git log
git log --oneline        # 簡潔顯示
git log --graph --oneline --decorate # 圖形化顯示分支合併
```

### 回溯更改

-   **撤銷最新提交 (不保留更改)**：
    ```bash
    git reset --hard HEAD~1
    ```
-   **撤銷最新提交 (保留更改在工作目錄)**：
    ```bash
    git reset HEAD~1
    ```
-   **撤銷特定文件在特定提交中的更改**：
    ```bash
    git checkout <commit_hash> <file_path>
    ```

### Revert 提交

創建一個新的提交來撤銷指定提交的更改，保留歷史記錄：

```bash
git revert <commit_hash>
```

## 5. 標籤 (Tags)

### 列出標籤

```bash
git tag
```

### 創建標籤

```bash
git tag -a v1.0 -m "版本 1.0"
```

### 推送標籤

```bash
git push origin --tags
```

## 總結

Git 是一個功能強大的版本控制系統，掌握這些基本命令可以讓你有效地管理程式碼、協同工作並應對各種開發場景。這篇備忘錄只涵蓋了 Git 的一部分功能，還有更多進階功能（如 `rebase`, `cherry-pick`, `submodule` 等）等待探索。
