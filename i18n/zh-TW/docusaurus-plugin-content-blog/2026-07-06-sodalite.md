使用 Stable Diffusion 生成圖片的方法有很多種，但 Web UI 類型的工具往往需要建置 Python 環境、管理相依套件，過程相當繁瑣。

想要更簡單、只要下載安裝程式就能使用的桌面應用程式，於是從零開始開發了 **Sodalite**。

GitHub: https://github.com/Himeyama/Sodalite

## Sodalite 是什麼

Sodalite 是一款透過 Stable Diffusion 進行圖片生成的 Windows 桌面應用程式。

特色在於從前端到後端全部都是自行開發實作。

- **前端**: WinUI3 (.NET 9 / Windows App SDK)
- **後端**: Python 3.13 以上 / FastAPI / diffusers (以 uv 管理)
- **通訊方式**: 前端將後端以本機子行程 (subprocess) 的方式啟動，並透過 HTTP 進行通訊

## 主要功能
- 從文字生成圖片 (txt2img)

安全檢查器 (safety checker) 已停用，因此也支援生成 NSFW 圖片。生成內容的使用與公開，須遵守所使用模型的授權條款以及使用者所在地的法令。

## 安裝方式
只要從 [Releases](https://github.com/Himeyama/Sodalite/releases) 下載最新版的 EXE 檔案即可使用。

由於是個人開發的應用程式，瀏覽器可能會暫時封鎖下載。此時可從「⋯」選擇「儲存」，確認警告訊息後保留檔案即可。基於安全考量，安裝程式是透過 GitHub Actions 自動建置的。

事前需要先安裝 `uv` 指令。

uv 安裝方式: https://docs.astral.sh/uv/#installation

安裝程式為不需要系統管理員權限的使用者層級安裝，會安裝至 `%LOCALAPPDATA%\Programs\Sodalite\`。虛擬環境 (`.venv`) 並未一併封裝，首次啟動時前端會執行 `uv sync` 來安裝 torch 等相依套件。由於會產生數 GB 的下載量，可能需要數分鐘到數十分鐘不等。

安裝設定的成功與否會連同 `uv.lock` 的雜湊值一併記錄，若失敗，下次啟動時會自動重新進行設定。應用程式更新導致相依套件變更時，也會重新同步。

首次啟動時，會自動從 Hugging Face 下載預設的圖片生成模型 (`stabilityai/sd-turbo`)。

## GPU 需求
建議 VRAM 12 GiB 以上，不過 10 GiB 也大致可以運作。

## 開發者用設定
若要從原始碼建置並執行，步驟如下。

```powershell
# 安裝後端相依套件
cd backend
uv sync
```

```powershell
# 於根目錄執行: 一次完成後端同步 + 前端建置 + 啟動
./run.ps1
```

若只想單獨確認後端運作情況，可依下列方式操作。

```powershell
cd backend
./run.ps1
# 於另一個終端機
curl http://localhost:8000/api/v1/health
```

Python 後端的 Lint、格式化、測試以下列指令執行。

```powershell
cd backend
uv run ruff check --fix .
uv run ruff format .
uv run pytest
```

前端的建置方式如下。

```powershell
cd frontend/Sodalite
dotnet build -c Debug
```

程式撰寫規範整理於 `skills/python-coding/SKILL.md` 與 `skills/winui3-app/SKILL.md`。

## API 概要

後端提供自行設計的 REST API (`/api/v1/*`)。

| 方法 | 路徑 | 說明 |
|---|---|---|
| GET | `/api/v1/health` | 啟動確認、載入中的模型、裝置資訊 |
| GET | `/api/v1/samplers` | 可用取樣器 (sampler) 清單 |
| POST | `/api/v1/generations/text-to-image` | txt2img 生成 |

## 目錄結構

```text
Sodalite/
├── backend/           # Python 後端 (uv 管理, FastAPI + diffusers)
│   ├── src/sodalite_backend/
│   │   ├── main.py            # FastAPI 進入點
│   │   ├── config.py          # 啟動設定(連接埠・模型 ID)
│   │   ├── api/                # REST API 端點
│   │   ├── schemas/            # Pydantic 請求/回應模型
│   │   ├── inference/           # diffusers 管線管理・取樣器
│   │   └── imaging/            # PNG 中繼資料嵌入・圖片儲存
│   └── tests/
├── frontend/Sodalite/    # WinUI3 前端
│   ├── MainWindow.xaml(.cs)    # 後端啟動・導覽
│   ├── Views/GenerationPage    # 提示詞輸入・生成・圖片顯示
│   ├── ViewModels/              # GenerationViewModel
│   └── Services/                # BackendProcessManager, BackendApiClient
├── docs/               # 設定紀錄等文件
├── skills/             # 開發規範 (winui3-app, python-coding)
├── run.ps1             # 應用程式啟動指令碼(根目錄)
└── CLAUDE.md
```

將 WinUI3 與 Python 後端組合起來的架構相關資料不多，過程中有不少摸索，最後採用了以本機子行程啟動、並透過健康檢查 (health check) 進行同步的方式。
