為了應付想把 Markdown 撰寫的文件轉換成 Word (docx) 的情境，打造了完全在瀏覽器內完成作業的編輯器「DOC」。內文不會傳送到伺服器，轉換作業也全部在瀏覽器內完成。

## DOC 是什麼

DOC 是可在 [/doc](/doc) 使用的迷你應用程式，可以一邊比對左側的 Markdown 編輯器與右側的預覽畫面一邊撰寫文件，完成後即可直接下載成 docx 檔案。編輯器採用 Monaco Editor (與 VS Code 相同的編輯器元件)，因此語法高亮與流暢的游標操作都能直接沿用。

## 主要功能

### Markdown 編輯與即時預覽

畫面採左右分割，左側為 Markdown 編輯器,右側為預覽畫面。拖曳分隔線即可自由調整寬度。捲動編輯器時，預覽畫面也會同步捲動。

### 一鍵轉換成 docx

點擊工具列上的按鈕，即可從輸入的 Markdown 產生 OOXML (docx 內部的 XML)，並在瀏覽器內打包成 zip，下載為 `.docx` 檔案。內文不會傳送到外部伺服器。

支援標題、段落、粗體/斜體/刪除線、項目符號清單、編號清單、程式碼區塊、引言、表格等常見的 Markdown 語法，轉換後的檔案也能直接在 Word 中開啟並編輯。

### 透過 OOXML 分頁直接確認轉換結果

切換到與預覽並列的「OOXML」分頁，即可在編輯器上直接查看轉換後的 XML。想了解 docx 內部是如何組成的時候相當方便。

:::tip
關於 docx 內部的封裝結構，先前在 [用文字編輯器嘗試製作 docx 檔案](/zh-TW/blog/2026/07/18/handmade-docx) 這篇文章中也曾提及。可以把 DOC 想成是自動完成該 OOXML 產生與封裝作業的工具。
:::

### 格式化工具列

選取文字後，點擊粗體、斜體、刪除線按鈕，即可自動加上或移除對應的 Markdown 語法 (`**`, `*`, `~~`)。也支援組合套用，例如同時套用粗體與斜體時會變成 `***text***`。

### 字型選擇

可從包含 Noto Serif JP / Noto Sans JP 在內的明體、黑體、複合字型中選擇輸出字型。選好的字型會立即反映在預覽畫面上，並會記錄在瀏覽器中，下次開啟時沿用。

### 匯入 Markdown / docx 檔案

除了既有的 `.md`、`.markdown` 檔案外，也可以透過拖放或選擇檔案的方式匯入 `.docx` 檔案。匯入 `.docx` 檔案時會反向轉換成 Markdown，適合在既有 Word 文件的基礎上繼續編輯。

### AI 聊天面板

開啟支援 OpenRouter 的 AI 聊天面板後，可以請 AI 產生文件內容、將回覆套用到選取的範圍，或是直接以回覆內容取代整份文件。也支援提示詞快取 (prompt caching)，即使針對同一份文件持續對話，也能避免浪費不必要的 token。

### 自動儲存

編輯中的內文會以防抖動 (debounce) 的方式自動儲存到瀏覽器的 localStorage。即使不小心關閉分頁，下次開啟頁面時也能從中斷處繼續編輯。

## 總結

- [/doc](/doc) 是可將 Markdown 轉換成 docx 的瀏覽器內建編輯器
- 具備 Monaco Editor 編輯功能與即時預覽，並可透過 OOXML 分頁確認轉換內容
- 支援粗體/斜體/刪除線工具列、字型選擇、Markdown/docx 匯入
- 支援 OpenRouter 的 AI 聊天面板也能協助產生與編輯文件
- 內文會自動儲存到本機儲存空間，且所有轉換作業皆在瀏覽器內完成，不會傳送到伺服器

下次想用 Markdown 快速寫份會議記錄或規格文件、再直接以 Word 格式分享時，不妨試試看。
