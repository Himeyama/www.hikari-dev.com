## 帶索引的 for 迴圈

```js
for([i, e] of ["a", "b", "c"].entries()){
    console.log(i, e)
}
```

### 也可以用 forEach
```js
["a", "b", "c"].forEach((e, i) => {
    console.log(e, i)
})
```

## 建立長度為 n 的陣列
```js
const n = 10
let ary = [...Array(n)].map((_, i) => i)
// 或者
ary = Array.from({length: n}).map((_, i)=> i)
```

## 陣列求和
```js
let ary = [1, 2, 3, 4, 5]
ary.reduce((_, v) => _ + v)
```
