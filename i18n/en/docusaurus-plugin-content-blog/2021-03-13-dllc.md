## Notes on creating a DLL and compiling C

## Library
### Source file
```c
// gcd.c
int gcd(int a, int b){
   return !b ? a : gcd(b, a % b);
}
```

### Header file
```c
// gcd.h
#ifndef TEST_H
#define TEST_H

int gcd(int a, int b);

#endif
```

### Program
```c
#include <stdio.h>
#include "gcd.h"

int main(void){
   printf("%d\n", gcd(24, 36));
}
```

## Compilation

### Creating the DLL
```sh
gcc gcd.c -shared -o gcd.dll
```

### Compile
```sh
gcc main.c -lgcd -L.
```
