|Command|Function|
|:-:|:-:|
|`dotnet new`|Create a new project|
|`dotnet add`|Add a package|
|`dotnet remove`|Remove a package|
|`dotnet publish`|Publish an app to a directory|
|`dotnet run`|Run the project|
|`dotnet sln`|Manage solution files|

## dotnet new

### Example
```ps1
dotnet new wpf
```

## dotnet add
### Example
```ps1
dotnet add package Microsoft.Web.WebView2
```

## dotnet remove
### Example
```ps1
dotnet remove package Microsoft.Web.WebView2
```
