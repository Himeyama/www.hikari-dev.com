## Creating Graphs

First, import the required libraries.

```py
import matplotlib.pyplot as plt
import numpy as np
```

### Single Graph

```py
fig, ax = plt.subplots()
```

![](/img/blog/2024-04-20-pyplot/001.png)

### 2 x 3 Graphs

```py
fig, axs = plt.subplots(2, 3)
```

![](/img/blog/2024-04-20-pyplot/002.png)

## Plotting Graphs

**Plotting a parabola**

```py
x = np.linspace(-1, 1, 201)
y = x ** 2

fig, ax = plt.subplots()
ax.plot(x, y)
```

![](/img/blog/2024-04-20-pyplot/003.png)

**Plotting a parabola with points**

```py
fig, ax = plt.subplots()

x = np.linspace(-1, 1, 21)
y = x ** 2

ax.plot(x, y, 'o')
```

![](/img/blog/2024-04-20-pyplot/016.png)

**Setting color to orange**

```py
fig, ax = plt.subplots()

x = np.linspace(-1, 1, 21)
y = x ** 2

ax.plot(x, y, color="tab:orange")
```

![](/img/blog/2024-04-20-pyplot/017.png)

Standard colors are as follows:

|Color|String|
|--|--|
|Blue|tab:blue|
|Orange|tab:orange|
|Green|tab:green|
|Red|tab:red|
|Purple|tab:purple|
|Brown|tab:brown|
|Pink|tab:pink|
|Gray|tab:gray|
|Olive|tab:olive|
|Cyan|tab:cyan|

**Setting line width to 4**

```py
fig, ax = plt.subplots()

x = np.linspace(-1, 1, 21)
y = x ** 2

ax.plot(x, y, lw=4)
```

![](/img/blog/2024-04-20-pyplot/018.png)

## Setting Ticks

**Setting x-axis ticks**

```py
fig, ax = plt.subplots()
xticks = range(6)
ax.set_xticks(xticks)
```

![](/img/blog/2024-04-20-pyplot/019.png)

**Setting x-axis ticks and tick labels**

```py
fig, ax = plt.subplots()
xticks = range(6)
ax.set_xticks(xticks, [f"{xtick}m" for xtick in xticks])
```

![](/img/blog/2024-04-20-pyplot/020.png)

**Setting y-axis ticks**

```py
fig, ax = plt.subplots()
yticks = [i * 20 for i in range(6)]
ax.set_yticks(yticks)
```

![](/img/blog/2024-04-20-pyplot/021.png)

**Setting y-axis ticks and tick labels**

```py
fig, ax = plt.subplots()
yticks = [i * 20 for i in range(6)]
ax.set_yticks(yticks, [f"{ytick}%" for ytick in yticks])
```

![](/img/blog/2024-04-20-pyplot/022.png)

## Adjusting Graph Spacing

**Setting vertical spacing to 0.2 and horizontal spacing to 0.3**

```py
fig, ax = plt.subplots(3, 3)
fig.subplots_adjust(hspace=0.2, wspace=0.3)
```

![](/img/blog/2024-04-20-pyplot/031.png)

**Setting spacing to automatic**

```py
fig, ax = plt.subplots(3, 3)
fig.tight_layout()
```

![](/img/blog/2024-04-20-pyplot/032.png)

## Saving Images

**Saving as PNG**

```py
fig, ax = plt.subplots()
plt.savefig("graph.png")
```

![](/img/blog/2024-04-20-pyplot/graph.png)

**Saving as SVG**

```py
fig, ax = plt.subplots()
plt.savefig("graph.svg")
```

![](/img/blog/2024-04-20-pyplot/graph.svg)

**Saving as PDF**

```py
fig, ax = plt.subplots()
plt.savefig("graph.pdf")
```

[graph.pdf](/img/blog/2024-04-20-pyplot/graph.pdf)

**Saving at 300 dpi**

```py
fig, ax = plt.subplots()
plt.savefig("graph300.png", dpi=300)
```
