---
title: How to Create an Icon (.ico)
date: 2021-05-09
description: How to create icons such as favicons
---

1. Create an icon.

    ![How to create an icon](/img/blog/2021-05-09-favicon/1.webp)

1. Prepare seven PNG images of sizes `16`, `24`, `32`, `48`, `64`, `128`, and `256`.
    ![How to create an icon](/img/blog/2021-05-09-favicon/2.webp)

1. Create an icon using the `convert` command.
    ![How to create an icon](/img/blog/2021-05-09-favicon/3.webp)

```sh
convert *.png favicon.ico
```
